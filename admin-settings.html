🤖 AI自動生成 (Gemini API) 設定

記事の自動生成機能を利用するためには、Google Gemini APIキーが必要です。
このキーはあなたのお使いのブラウザ（ローカル環境）に安全に保存され、生成時のみサーバーへ送信されます。

【APIキーの取得手順】
  1. Google AI Studio にアクセスし、Googleアカウントでログインします。
  2. 画面左側の「Get API key」または「Create API key」ボタンをクリックします。
  3. 「Create API key in new project」を選択すると、AIzaSy...から始まるキーが生成されます。
  4. 生成されたキーをコピーし、上の入力欄に貼り付けて保存してください。
※空欄にして保存した場合は、サーバーに設定されているデフォルトのキー（Vercel環境変数など）が使用されます。
